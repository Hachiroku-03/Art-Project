# 🎨 Art Gallery - Real-Time Auction & Showcase Platform

A full-stack web application for showcasing and auctioning artwork in real-time, with built-in multi-language translation support.

## 🚧 Status: **In Development**

This project is currently being built. The WebSocket backend is functional!

## ✨ Features

### ✅ Completed
- **WebSocket Backend:** Real-time server handling multiple clients
- **Live Bidding System:** Instant broadcast of auction bids
- **Real-Time Chat:** Live comments and discussions

### 🔜 Planned
- **Frontend Interface:** HTML/CSS/JavaScript gallery and auction pages
- **Real-Time Translation:** Auto-translate comments based on user language settings
- **User Authentication:** Login and profile management
- **Database Integration:** Save bids, comments, and artwork
- **Reply System:** Threaded comments for organized discussions

## 🛠️ Tech Stack

- **Backend:** Python, WebSockets, AsyncIO
- **Frontend:** HTML, CSS, JavaScript (Coming soon)
- **Translation:** Google Translate API (Planned)
- **Database:** TBD
